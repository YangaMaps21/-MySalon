# Welcome Hero Page — @MySalon

Landing / welcome hero page design for @MySalon (www.atmysalon.co.za).

Flow: hero photo slider + gold glitter + glass logo -> pulsating "Enter" orb
-> clickable South Africa province map (9 provinces) -> Terms & Conditions
-> main site at https://www.atmysalon.co.za?terms=accepted&province=<slug>

## Contents
- project/Main.dc.html   main design file (Claude Design canvas component)
- project/canvas.json     canvas configuration
- assets/                 hero photos + logo variants
